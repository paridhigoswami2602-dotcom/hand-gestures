# Hand Gesture Recognition

A computer vision and deep learning based project for recognizing hand gestures using OpenCV and TensorFlow.

## Features

- Hand gesture detection
- Hand landmark extraction
- Gesture classification
- Real-time camera-based recognition

## Technologies Used

- Python
- OpenCV
- TensorFlow
- MediaPipe
- NumPy
